# チュートリアル

オトクリは、画面の決めた場所を自動でタップ／スワイプするアプリです。ルートは不要です。この画面はオフラインでも読めます。

## 1. 最初にやること（権限）

再生や記録の前に、次の許可が必要です。ホームや設定のボタンからシステム画面へ飛べます。

### 他のアプリの上に表示（オーバーレイ）

フローティング操作パネル、記録レイヤー、かんたん配置の点／棒を出すために使います。オフだと画面の上に何も出せません。

1. オトクリのホームで「許可」を押す
2. オトクリをオンにする
3. 戻って、状態が「操作バブルを表示できます」になっているか確認

### ユーザー補助（オトクリ ジェスチャー実行）

指定した座標へタップとスワイプを送るためだけに使います。キー入力の記録、パスワードの読み取り、通信はしません。

1. ホームの「設定」からユーザー補助一覧を開く
2. 「オトクリ ジェスチャー実行」をオンにする
3. 説明を読んで許可する

### 制限付き設定（Android 13 以降でよくあるつまずき）

ユーザー補助がグレーアウトしてオンにできないときは、制限付き設定でブロックされています。

1. 設定 → アプリ → オトクリ（debug 版は「オトクリ」の debug パッケージ）
2. 右上の「︙」メニュー → **制限付き設定を許可**
3. もう一度ユーザー補助に戻り、「オトクリ ジェスチャー実行」をオン

通知（Android 13+）は操作パネルを前面に出すためのものです。自動化そのものには使いません。

## 2. かんたんモード（点と棒）

ゲームやアプリの上に、タップ用の点とスワイプ用の棒を置いて再生します。

1. ホームで「画面に置いて開始（クリック／スワイプ棒）」
2. オレンジはスワイプの始点、青は終点。棒をドラッグして伸ばす／縮める
3. 緑の点はタップ位置。長押しで削除
4. パネルで間隔（ミリ秒）と回数を決める。回数 0 は無限
5. 「開始」でカウントダウンのあと再生
6. 「保存」でプロファイルとして残す。「閉じる」で配置を終了

下方向から上方向へ伸ばした棒は、下から上へのスワイプになります。

## 3. 記録モード

画面上の操作をタイムスタンプ付きで覚え、マクロとして再生します。記録中は下のアプリにタッチは届きません（「教える」方式です）。

1. ホームの「記録モード」→「記録を開始」、または記録画面の赤いボタン
2. 対象アプリを開いて、教えたいタップ／スワイプをする
3. **記録を保存**でマクロになる
4. いらないときは **キャンセル**（記録だけ破棄してパネルは残る）
5. 画面が貼りついた・触れないときは、必ず **閉じる**

### 閉じる（いちばん大事）

記録パネルの大きな「閉じる」、画面下の「閉じる」、通知の「閉じる」はどれも同じです。

- 記録中ならすぐ停止（保存確認は出ません）
- キャプチャレイヤー、ピンクのターゲット、ハンドル、パネルを全部外す
- 通常のホーム操作に戻る

閉じるが押せないときは、通知シェードを下に引いて「閉じる」を押してください。

## 4. フローティング操作

「フローティング操作を表示」で小さなバブルが出ます。ドラッグで移動できます。

- 再生／一時停止／停止
- かんたん／記録のモード切替
- 記録中はパネルが自動で開いたままになります
- バブルや通知の「閉じる」でオーバーレイ全体を終了

## 5. 安全に使う

- 使っていないときはユーザー補助をオフにしてください
- オーバーレイも「閉じる」で消してください
- パスワード欄や送金画面では使わないでください
- 他人の端末や、利用規約で禁止されている自動化には使わないでください
- オトクリは端末内だけに保存します。通信権限はありません
